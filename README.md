# みらい家計 / MiraiLedger

金融資産と家計を入力すると、毎月の余剰資金・運用利回りから将来の資産を試算できるiPhoneアプリです。SwiftUI / Swift Charts、iOS 17以降対応。外部ライブラリ、サーバー、APIキーは不要です。

## v1.1で追加した機能

- **家計レポート**：「家計簿」左上のグラフから、6か月・12か月の収入／支出の推移、選択月の収支、カテゴリ別の支出と予算を確認できます。未記録の収支は含みません。過去月も、現在の予算との比較です。
- **実績から予算を作成**：レポート右上から、終了した1・3・6か月の記録を平均し、変更前後の予算を確認して反映できます。同じ収入／支出・カテゴリの予算をまとめて更新し、記録のないカテゴリは元の予算を残します。資産評価額と日々の記録は変更しません。
- **暮らしのプラン比較**：「シミュレーション → もしものプランを比較」で、毎月の収入・支出の増減、投資配分、年利の増減を変えたプランを最大20件保存。基本プラン＋選択した3件をグラフで比較し、期間末の差額・目標到達時期・資金不足を確認できます。編集・削除にも対応しています。

比較プランが保存するのは変更条件です。現在の資産・予算・イベント・NISA利用額・開始日・期間を共通に使うため、基本データを更新すると保存済みプランの試算も更新されます。比較プランを保存しても基本プランは変わりません。収支が0円未満になる減額や、許容範囲外の利回りはエラーとして表示します。

実績の平均には未記録の月も0円として含めます。少ない記録から作った予算が普段の生活費を下回ることがあるため、画面に期間・記録のある月数・更新額を表示します。平均額は小数を保持し、表示のみ円単位へ丸めます。

旧バージョンの保存データ・JSONバックアップを読み込めます。読み込むだけではファイルを変更せず、次回保存時に比較プランを含む形式（schemaVersion 2）へ更新します。新形式は旧アプリでは読み込めません。サンプルには過去6か月の架空記録と2つの比較プランを追加しています。

## できること

- **ホーム**：資産合計、現金と運用資産の内訳、毎月の収入・支出・余剰資金、将来の資産見通し。
- **資産管理**：現金・預金、株式、投資信託、その他を登録。資産ごとの評価額・利回り・積立の配分を編集。
- **家計簿**：手取り収入・食費・家賃・光熱費などの月次予算と、日々の収入・支出の記録。月別集計、予算との比較、追加・編集・削除。
- **シミュレーション**：1〜600か月を月単位で試算。グラフとスライダーで任意の月を確認。元本＋収支累計と運用益を区別し、現金・投資・物価調整後の金額も表示。
- **シナリオ比較**：標準・慎重（運用資産の年利−2ポイント）・積極（＋2ポイント）を切り替え。
- **目標とイベント**：目標資産額の初回到達時期、旅行・買い替えなどの臨時支出や臨時収入を反映。
- **NISA**：資産種類とは別に口座区分として設定。取得額と年内利用額から投資枠を管理。超過分は現金へ。
- **保存**：端末内に自動保存、JSONバックアップの書き出し・確認付き復元。読み込みに失敗した既存データを空データで上書きしません。

初回は空の状態です。ホームから資産と月次予算を入力するか、「サンプルで体験する」で架空のデータを試せます。サンプルには投資先の推奨は含みません。設定から初期化できます。

## 最初の使い方

1. 「資産」で基準日時点の預金・株式・投資信託の評価額を登録します。
2. 「家計簿 → 毎月の予算」で、手取り収入と普段の支出を登録します。
3. 「シミュレーション」右上で期間、余剰資金を投資する割合、目標、基準日を設定します。
4. 資産ごとの「積立配分の重み」を設定します。70と30なら積立予定額を7:3に配分。0なら積立対象外です。
5. NISAは各保有資産の取得額と、設定内の今年の利用済み投資枠を入力してください。

基準日と資産評価額は同じ時点のものを使います。日々の記録を見ながら将来の月次予算を調整し、資産の評価額・基準日を定期的に更新してください。

## 計算の前提

日々の家計簿は振り返りのための記録です。入力済みの現在評価額や将来の予算へ自動加算しません。実績と想定を分けることで二重計上を防ぎます。

運用資産の月利は `(1 + 年利 / 100)^(1/12) - 1`。月初資産を運用した後、月末に毎月の予算とその月のイベントの差額を反映し、指定割合を積み立てます。積立分に同月の利息を重ねて加算しません。現金・預金は0%としてまとめて扱います。投資先がない場合や全配分が0の場合は現金に残します。

赤字時は現金、次に運用資産を評価額に比例して取り崩します。使い切った後は不足額を累積して純資産から差し引き、将来の黒字で先に解消します。不足額への利息は計算しません。元本＋収支累計には臨時支出と赤字も含み、マイナスになることがあります。

表示額は**売却前の評価額**で、譲渡益税・分配金課税・手数料の自動控除は行いません。利回りは固定の仮定であり、予測や確率を示しません。インフレ調整は将来の純資産を現在の購買力へ割り引く計算で、毎月の収入・支出自体は増額しません。年利入力は−99〜100%、物価上昇率は−20〜30%、試算は最長50年です。

NISAはつみたて投資枠年120万円・成長投資枠年240万円、簿価総額1,800万円・うち成長投資枠1,200万円を上限とします。同一区分の複数資産で枠を共有し、年間枠は日本時間の年替わりに更新します。売却時の簿価分は翌年から保有限度額を再利用できます。超過した積立予定額はその時点で現金に回し、あとで自動投資しません。商品適格性の判定、旧NISA、他口座の自動取得は対象外です。制度資料：[金融庁 NISAを知る](https://www.fsa.go.jp/policy/nisa2/know/index.html)（2026-10-01確認）。

## 保存とバックアップ

`Library/Application Support/MiraiLedger/household.json` に検証後アトミックに保存します。iOSのファイル保護を設定しています。JSONバックアップには資産・家計のデータが含まれ、アプリ独自のパスワード暗号化はありません。最大50MBです。

破損データの読み込み時は保存を停止します。再読み込み、または設定から正常なバックアップの復元が可能です。破損ファイルを復元する場合、元のファイルは別名で保持されます。アプリ削除で端末内データも削除されるため、機種変更前に書き出してください。

銀行・証券との自動連携、株価取得、クラウド同期、Face ID認証、実際の売買は含みません。

## ビルドと検証

`MiraiLedger.xcodeproj` をXcodeで開き、Scheme「MiraiLedger」とiPhoneシミュレータを選択してRunしてください。

```sh
cd MiraiLedger
swift test
bash Scripts/build_simulator.sh
bash Scripts/test_ui.sh
```

実機で使う場合は `Config/Signing.local.xcconfig.example` を `Config/Signing.local.xcconfig` にコピーし、自分のApple Development Teamを設定してXcodeからRunします。実機導入は別途署名と端末の信頼設定が必要です。

UIテストは `--uitesting` のときだけ別フォルダ `MiraiLedger-UITests` を使用。`--reset-data` と `--sample-data` もテスト時のみ有効です。通常データに影響しません。

検証結果は `Artifacts/`、構成は `App/`（SwiftUI）、`Core/`（計算・検証・保存）、`Tests/`（単体テスト）、`UITests/`（実画面操作）です。v1.1の結果と画面は [機能拡充の検証記録](Artifacts/ExpansionVerification.md)、初版の記録は [初版の検証記録](Artifacts/Verification.md) を参照してください。
